# KVS Bot - Бот вакансий для университета

Телеграм-бот на aiogram + PostgreSQL для отображения вакансий по факультетам.

## Установка

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Создайте файл `.env` на основе `.env.example` и заполните его:
   - `BOT_TOKEN` - токен бота от @BotFather
   - `ADMIN_IDS` - ID администраторов через запятую
   - Настройки PostgreSQL
   - Настройки Google Sheets

3. Для работы с Google Sheets:
   - Создайте проект в Google Cloud Console
   - Включите Google Sheets API
   - Создайте сервисный аккаунт и скачайте JSON ключ
   - Сохраните файл как `credentials.json`
   - Поделитесь Google таблицей с email сервисного аккаунта

4. Создайте базу данных PostgreSQL:
```sql
CREATE DATABASE kvs_bot;
```

5. Запустите бота:

**Локально:**
```bash
python main.py
```

**Или через Docker Compose (рекомендуется):**
```bash
# Создайте файл .env на основе env.example
cp env.example .env
# Заполните все необходимые переменные

# Запустите контейнеры
docker-compose up -d

# Просмотр логов
docker-compose logs -f bot

# Остановка
docker-compose down
```

При запуске через Docker Compose:
- PostgreSQL запускается автоматически
- Миграции применяются автоматически при старте бота
- Данные сохраняются в volume `postgres_data`

## Команды

- `/start` - регистрация нового пользователя
- `/vacancies` - просмотр вакансий (доступно после регистрации)
- `/admin` - админ панель (только для администраторов)
- `/sync_vacancies` - синхронизация вакансий из Google Sheets (только для администраторов)

## Функционал

### Для пользователей:
- Регистрация с указанием имени, фамилии, курса, факультета и источника информации
- Просмотр вакансий, подходящих для своего факультета
- Просмотр всех вакансий
- Навигация по вакансиям с помощью кнопок "Назад" и "Вперед"
- Просмотр своих настроек

### Для администраторов:
- Статистика по пользователям (всего, зарегистрировано, по факультетам, по источникам)
- Статистика по вакансиям
- Синхронизация вакансий из Google Sheets

## Структура проекта

- `main.py` - точка входа
- `config.py` - конфигурация
- `database/` - модели и подключение к БД
- `handlers/` - обработчики команд
- `services/` - сервисы (парсинг Google Sheets)
- `Dockerfile` - образ для Docker
- `docker-compose.yml` - конфигурация Docker Compose
- `scripts/` - вспомогательные скрипты
  - `generate_vacancies.py` - генератор тестовых вакансий

## Генерация тестовых вакансий

Для создания тестовых данных используйте скрипт генерации:

```bash
# Генерация 50 вакансий и автоматическая загрузка в Google Sheets
python scripts/generate_vacancies.py

# Генерация указанного количества вакансий
python scripts/generate_vacancies.py 100

# Только CSV файл (без загрузки в Google Sheets)
python scripts/generate_vacancies.py 50 --csv-only

# Очистка существующих данных и добавление новых
python scripts/generate_vacancies.py 100 --clear
```

Скрипт:
- Создает файл `vacancies.csv`
- **Автоматически загружает данные в Google Sheets** (если настроено)
- Записывает данные начиная с 4-й строки (заголовки в 3-й строке)

**Требования для автоматической загрузки:**
- Настроен `.env` с `GOOGLE_SHEET_NAME`
- Файл `credentials.json` в корне проекта
- Google таблица доступна сервисному аккаунту

Подробнее см. `scripts/README_GENERATE.md`

## Docker

Проект полностью готов к запуску через Docker Compose:

1. **Создайте `.env` файл** с необходимыми переменными
2. **Поместите `credentials.json`** в корень проекта (для Google Sheets)
3. **Запустите:**
   ```bash
   docker-compose up -d
   ```

Миграции применяются автоматически при первом запуске контейнера бота.
