## Классификация фреймов

- Main screen: `Вакансии`, `Мероприятия`, `Мой профиль / Резюме`.
- Secondary screen: `Детальная вакансия`, `Профиль / Редактирование`.
- Onboarding/splash screen: `ФинКарьера`.
- Component/state frames: `Профиль / Избранное` является состоянием профиля, а не отдельным глобальным разделом.
- Navigation element: BottomNav с разделами `Вакансии`, `События`, `Профиль`.
- Card component: `VacancyCard`, `EventCard`.
- Form state: `0/5 шагов`, disabled `Сгенерировать резюме`.
- Empty state: явно не показан в Figma, нужен для списков вакансий, событий и избранного.
- Loading/error states: явно не показаны в Figma, добавляются как обязательные продуктовые состояния.

## Неоднозначные элементы Figma

1. `PDF page 03`, верхний правый колокол.
   - Почему непонятно: нет отдельного экрана уведомлений.
   - Вероятная трактовка: вход в уведомления.
   - Реализация: кнопка без отдельного route, показывает placeholder/error-neutral состояние через сервис позже.

2. `PDF page 04`, кнопка `Подробнее` у мероприятия.
   - Почему непонятно: отдельного экрана события в PDF нет.
   - Вероятная трактовка: переход к detail screen или внешней регистрации.
   - Реализация: пока открывает внешнюю ссылку/заглушку через mock-сервис; структура данных допускает добавление `event details`.

3. `PDF page 01`, степпер 1-5.
   - Почему непонятно: показан только первый шаг формы.
   - Вероятная трактовка: 5 шагов резюме: образование, цель, контакты, навыки, опыт.
   - Реализация: реализован первый шаг и теоретическая структура `profile.resumeSteps`, остальные шаги представлены в данных и могут быть расширены.

4. `PDF page 05`, `Скачать резюме как PDF`.
   - Почему непонятно: нет backend/pdf-generation контракта.
   - Вероятная трактовка: disabled до подключения генерации.
   - Реализация: disabled action до появления реального backend endpoint.

5. `PDF page 07`, зеленый градиентный cover.
   - Почему непонятно: в списке вакансий компании имеют разные цвета, но деталь показана только для Сбера.
   - Вероятная трактовка: брендовый cover компании.
   - Реализация: cover color берется из mock `company.brandColor`, fallback - красный KVS.
