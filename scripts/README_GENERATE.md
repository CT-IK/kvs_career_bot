# Генератор тестовых вакансий

Скрипт `generate_vacancies.py` генерирует тестовые вакансии и **автоматически загружает их в Google Sheets**.

## Использование

### Базовое использование (50 вакансий, загрузка в Google Sheets):
```bash
python scripts/generate_vacancies.py
```

### Указание количества вакансий:
```bash
python scripts/generate_vacancies.py 100
```

### Только CSV файл (без загрузки в Google Sheets):
```bash
python scripts/generate_vacancies.py 50 --csv-only
```

### Очистка существующих данных и добавление новых:
```bash
python scripts/generate_vacancies.py 100 --clear
```

## Требования

Для загрузки в Google Sheets необходимо:
1. Настроить `.env` файл с `GOOGLE_SHEET_NAME`
2. Иметь файл `credentials.json` в корне проекта
3. Поделиться Google таблицей с email сервисного аккаунта

## Результат

Скрипт:
- Создает файл `vacancies.csv` в корне проекта
- **Автоматически загружает данные в Google Sheets** (если настроено)
- Записывает данные начиная с 4-й строки (заголовки в 3-й строке)
- Автоматически добавляет заголовки, если их нет

Поля вакансий:

- Организация
- Вакансия
- Сфера
- ЗП
- График
- Формат
- Описание
- Формат трудоустройства
- Особенность 1
- Особенность 2
- Особенность 3
- ИТиАБД (Да/Нет)
- ФинФак (Да/Нет)
- ВШУ (Да/Нет)
- НАБ (Да/Нет)
- СНиМК (Да/Нет)
- МЭО (Да/Нет)
- ФЭБ (Да/Нет)
- Юрфак (Да/Нет)

## Автоматическая загрузка в Google Sheets

Скрипт автоматически:
1. Подключается к Google Sheets используя `credentials.json`
2. Проверяет наличие заголовков в 3-й строке (добавляет, если нет)
3. Записывает данные начиная с 4-й строки
4. Если данные уже есть, добавляет новые в конец (или очищает при `--clear`)

## Ручной импорт (если нужно)

Если хотите импортировать вручную из CSV:
1. Откройте вашу Google таблицу
2. Убедитесь, что заголовки находятся в 3-й строке
3. Выделите строку 4 (первая строка с данными)
4. Скопируйте содержимое из `vacancies.csv` (без заголовков!)
5. Вставьте в Google Sheets, начиная с 4-й строки

## Настройка

Вы можете изменить списки данных в скрипте:
- `ORGANIZATIONS` - список организаций
- `VACANCIES` - список вакансий
- `SPHERES` - сферы деятельности
- `SALARIES` - варианты зарплат
- `SCHEDULES` - графики работы
- `FORMATS` - форматы работы
- `EMPLOYMENT_FORMATS` - форматы трудоустройства
- `FEATURES` - особенности вакансий
- `DESCRIPTIONS` - описания вакансий

## Логика генерации

- Каждая вакансия случайным образом привязывается к 2-5 факультетам
- Для каждого факультета указывается "Да" или "Нет"
- Особенностей может быть от 1 до 3 на вакансию
- Все остальные поля выбираются случайно из соответствующих списков
